配置指引

从对话，到成诗

  1. 一
    连接对话模型（可选）若需要对话辅助，可以配置模型服务
  2. 二
    检查推理环境确认依赖、硬件与本地模型兼容
  3. 三
    启动本地生成器加载诗词生成模型，准备生成诗稿

设计有搜韵、搜词牌、格律检查等功能，用于交流、推敲创作思路；而本地生成器用于按格律生成诗稿，独立使用。即使未配置对话模型或连接 API，也可以打开创作面板，手动填写创作要求和生成参数；提交生成前，需先在下方配置并启动本地生成器。

如需对话辅助，可在下方添加模型服务端点。使用 Ollama、LM Studio 等本机对话服务时，填写服务地址并选择模型；是否需要密钥，以该服务的认证设置为准。

本地诗词生成模型

本地生成支持 Qwen3 / Qwen3.5 原始浮点权重。可用 CPU FP32 推理，建议使用较小模型；也可使用 NVIDIA CUDA，按显存采用 FP16 或 4bit。暂不支持预量化或 GGUF。扫描会列出发现的模型及不可用原因；权重加载、有效输出及约束生成全部通过后才会就绪。

运行方式由环境、模型与硬件检测自动决定，不需要手动选择精度。CPU 推理速度较慢；通过真实调用与约束生成验收后才会标记为就绪。

空闲超时才释放权重；驻留期间复用模型，释放后新任务会自动重新加载。运行中的任务不会被中断。
