# 卡片专属素材

`backgrounds/` 存放与专属构图绑定的完整背景，使用小写英文和连字符命名。

| 模板 | 模板标识 | 背景文件 | 原图尺寸 |
| --- | --- | --- | --- |
| 柳下吟诗 | willow-poet | backgrounds/willow-poet.png | 1672 × 941 |

柳下吟诗的图片由用户提供。左侧人物和边角柳枝为保护区域，右侧留白为文字区域；默认按原图比例导出。素材来源与授权说明应随新增素材补充，不能仅凭文件存在推定发布许可。

新增专属模板时，在模板目录注册名称、标识与背景路径，并在构图模块定义该图片的文字安全区域。不要依靠通用背景裁剪来决定人物位置。
