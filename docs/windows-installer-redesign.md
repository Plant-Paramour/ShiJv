# 诗矩 Windows 工业化安装器设计

## 目标

安装程序本身负责引导用户完成环境部署。用户只运行一个 `诗矩安装程序.exe`，不需要寻找 BAT、PowerShell 或单独的环境部署窗口。

## 结构

安装包包含 Inno Setup 向导和一个无界面的 `ShiJuSetupBootstrap.exe`。Bootstrap 复用现有部署核心，但不复用旧的 WinForms 环境部署界面。

Inno Setup 负责：

- 中文欢迎、许可、安装位置和快捷方式页面；
- 展示硬件检测、方案确认、下载进度、验证结果；
- 处理取消、重试、改用 CPU 和查看日志；
- 写入安装注册信息和卸载入口。

Bootstrap 负责：

- 检测 CPU、显卡、驱动、CUDA、内存和磁盘；
- 选择 CPU/GPU 安装方案；
- 下载并校验 Python、PyTorch、模型和其他组件；
- 创建独立运行环境；
- 执行真实导入、加载和生成验证；
- 通过 JSONL 状态文件向安装器报告阶段、进度和错误。

## 安装流程

1. 欢迎页说明将下载 Python、PyTorch、模型和运行组件。
2. 用户选择应用、环境和模型目录。
3. 安装器调用 Bootstrap 进行硬件检测。
4. 安装器展示推荐方案；GPU 不可用时明确推荐 CPU，并解释原因。
5. 用户确认后，安装器依次驱动下载、安装、模型准备和真实验证。
6. 失败时在当前页面显示中文原因，并提供重试、改用 CPU、查看诊断报告。
7. 完成验证后才创建“诗矩”快捷方式。

## 状态与恢复

- 每个阶段写入 `deployment-session.json` 和 JSONL 事件日志。
- 下载使用临时文件、哈希校验和断点续传。
- 取消安装不会删除已完成的缓存。
- 重新运行安装器时自动恢复已完成阶段。
- GPU 验证失败会记录硬件签名和具体错误；驱动、PyTorch 或工具版本变化后自动重新验证。

## 入口策略

- 普通用户只看到 `诗矩安装程序.exe` 和安装完成后的 `诗矩单机版.exe`。
- `诗矩环境部署.bat`、旧 WinForms 工具和 PowerShell 脚本只放入隐藏的 `support` 目录，作为维护救援入口。
- 安装器不再通过 `[Run]` 简单启动旧环境部署程序。

## 实施顺序

1. 将现有部署核心拆出无界面 Bootstrap 协议。
2. 为 Inno Setup 增加中文自定义页面和状态轮询。
3. 接入取消、重试、CPU 回退和断点恢复。
4. 只在验证成功后生成普通用户快捷方式。
5. 在干净 Windows 环境验证安装、失败恢复、卸载和再次安装。
